# 프론트엔드 화면 구상

작성일: 2026-09-14 · 상태: 피그마 작성용 초안

## 목적과 진행 시점

ShuttleBus 학생 화면을 피그마로 설계하기 위한 문서다. 현재는 화면 흐름과 표시 규칙만 정리한다. 실제 프론트엔드 구현과 서버 연동은 백엔드·서버 기능이 준비된 뒤 사용자와 구현 범위를 정하여 시작한다. 이 폴더 생성은 앱 구현·패키지 설치·서버 실행 요청이 아니다.

## 합의한 기능

- 입장 시 바로 지도 표시.
- 지도에 정류장 마커 표시. 클릭하면 해당 정류장의 가까운 예정 버스 최대 2개 표시.
- 상단 검색창을 누르면 출발지·도착지 선택.
- 오른쪽 메뉴 버튼을 누르면 다른 메뉴 표시. 마우스 오른쪽 클릭을 요구하지 않는다.
- 지도와 시간표 메뉴 제공.
- 예정 시각까지 1시간 미만이면 n분 뒤, 1시간 이상이면 시각 표시.

## 도안 제안 — 아직 확정 아님

- 모바일은 하단 카드, 넓은 화면은 지도 옆 상세 패널 사용.
- 세 번째 메뉴는 이용 안내. 공지사항은 선택 메뉴이며 주요 공지는 메인 배너로 제공.
- 정류장 카드에 ‘여기서 출발’, ‘여기로 도착’ 버튼 제공.
1분‘1분 이내’로 표시.
- 색상·글꼴·아이콘·간격은 피그마 도안에서 결정.

## 기존 설계와의 관계

기준은 ../md의 현재 v7.9 문서다. 특히 [공개 상태](../md/03-state-contract.md), [정거장 선택](../md/10-stop-discovery.md), [탑승 후보](../md/11-boarding-candidates.md), [실시간 전송](../md/12-realtime-delivery.md)을 따른다. 번호가 같은 프론트 문서와 혼동하지 않도록 기존 설계 참조는 경로를 함께 표시한다. 이 문서는 화면 초안이며 기존 데이터 계약을 조용히 변경하지 않는다.

정류장 하나만 눌러 예정 버스를 조회하는 기능은 이번에 추가한 요구다. 기존 11의 출발·도착 쌍 검색과 다르므로 서버 조회 계약을 별도로 협의해야 한다. 아직 구현된 API가 있다고 가정하지 않는다.

실측·예측·시간표를 구분하고 미확인 좌표나 시간을 만들어 표시하지 않는다. 과거 변경 근거는 참고용으로만 읽는다.
