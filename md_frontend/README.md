# 프론트엔드 화면 구상

작성일: 2026-09-14 · 갱신일: 2026-09-18 · 상태: 기본 레이아웃 합의 · 일부 연동 준비 중

## 목적과 진행 시점

ShuttleBus 학생 화면을 설계하기 위한 문서다. 피그마는 필수가 아니며 다른 도구의 도안이나 합의한 화면 구상으로도 진행할 수 있다. Transit 앱·PC 기반 기본 화면 범위와 배치를 합의했다. 별도 도안 없이 구현 초안을 만들 수 있다. 미완료 API는 기능별 계약 준비 후 연동한다.

## 합의한 기능

- 입장 시 바로 지도 표시.
- 지도에 정류장 마커 표시. 클릭하면 해당 정류장의 가까운 예정 버스 최대 2개 표시.
- 왼쪽 메뉴의 검색 또는 정류장 카드에서 출발지·도착지 선택.
- 왼쪽 위 햄버거 메뉴(☰)로 왼쪽 패널 열기. 검색·시간표와 맨 아래 프로필 이미지 제공. 이미지를 누르면 프로필 설정으로 이동.
- 기본 화면은 지도. 모바일은 Transit 앱의 하단 카드, PC는 Transit의 지도 옆 패널을 참고. Citymapper는 제외.
- 예정 시각까지 1시간 미만이면 n분 뒤, 1시간 이상이면 시각 표시.

## 도안 제안 — 아직 확정 아님

- 프로필 세부 설정은 구현 시 정리. 초기에는 학생 로그인 없는 기기 내 설정을 기준으로 한다.
- 별도 이용 안내·공지 메뉴는 추가하지 않는다. 이용 안내는 상세에, 공지는 배너에 제공.
- 정류장 카드에 ‘여기서 출발’, ‘여기로 도착’ 버튼 제공.
- 남은 시간이 0초보다 크고 1분 미만이면 ‘1분 이내’로 표시하는 방식을 제안한다. 분 단위 내림·올림은 화면 설계 시 확정한다.
- 색상·글꼴·아이콘·간격은 화면 도안에서 결정.

## 기존 설계와의 관계

기준은 ../md의 v7.10 변경 기록과 2026-09-18 운영 결정을 반영한 문서다. 특히 [공개 상태](../md/03-state-contract.md), [정거장 선택](../md/10-stop-discovery.md), [탑승 후보](../md/11-boarding-candidates.md), [실시간 전송](../md/12-realtime-delivery.md)을 따른다. 번호가 같은 프론트 문서와 혼동하지 않도록 기존 설계 참조는 경로를 함께 표시한다. 이 문서는 화면 초안이며 기존 데이터 계약을 조용히 변경하지 않는다.

정류장 하나만 눌러 예정 버스를 조회하는 기능은 이번에 추가한 요구다. 기존 11의 출발·도착 쌍 검색과 다르므로 서버 조회 계약을 별도로 협의해야 한다. 아직 구현된 API가 있다고 가정하지 않는다.

실측·예측·시간표를 구분하고 미확인 좌표나 시간을 만들어 표시하지 않는다. 과거 변경 근거는 참고용으로만 읽는다.
