# 05 · 디자인 준비 메모 — 서버 작업에서 나온 화면 상태

- 분야: 화면
- 작업: SB-0102

디자인은 따로 정한다 (2026-09-29 사용자). 이 문서는 **디자인을 바로 시작할 수 있게** 서버 작업 중에 드러난 화면 상태·문구 후보를 쌓아 두는 곳이다. 규칙은 각 소유 문서에 있고 여기서는 가리키기만 한다. 서버 작업이 화면에 새 상태를 만들면 이 표에 한 줄을 더한다.

도안의 전체 틀(상태별 도안·검토 항목)은 [03](03-figma-handoff.md), 카드 문구는 [02](02-stop-upcoming.md), 화면 구성은 [01](01-screens.md)이 소유한다.

## 실제 화면을 보면서 디자인하기

루트 `서버.cmd`를 더블클릭하면 DB·API·참고 화면이 켜지고 브라우저가 `http://localhost:3000`을 연다 (README "한 번에 실행"). 아래 상태는 가짜 화면이 아니라 이 서버의 실제 응답에서 나온다. 2026-09-29 기준 응답에서 확인한 것:

- 노선 목록, 정거장 목록(패턴별), 정거장 카드(`/stops/{id}/upcoming`), 경로(`/routes/{id}/path`), 실시간 연결(`/socket.io`)이 모두 응답한다.
- 정거장 좌표는 **임시 7개만** 있다 (`needs_interpretation`). 나머지는 좌표 없음(`unverified`)이라 지도에 점이 없고 목록에만 나온다.
- 실시간 관측이 없어 카드 시각은 전부 시간표 기준(`display_basis: timetable`)이다.

## 서버가 내는 상태와 디자인이 정할 것

| 상태 (응답 값) | 지금 실제로 나오나 | 디자인이 정할 것 | 규칙 소유 |
|---|---|---|---|
| 정거장 좌표 `needs_interpretation` | 예 — 임시 좌표 7개 | '위치 확인 필요' 마커 모양. 확정 마커와 색만으로 구분하지 않기 | `md/10` 3장, [must_do](must_do.md) |
| 정거장 좌표 없음 (`latitude: null`) | 예 — 15개 | 지도에 없는 정거장을 목록에서 어떻게 보일지 | `md/10` 3장 |
| 경로 `verification: none` | 예 — 녹화 경로 없음 | 선 없이 마커만 있는 지도가 비어 보이지 않게 | `md/10` 5장 |
| 경로 `partial`·`unverified` | 녹화 경로를 적재하면 | 점선 + "미검증 경로" | `md/10` 5장 |
| 녹화 중 **수신 공백** → 공백 뒤 조각을 버림 | 적재 시 | 경로가 중간에서 끝나 보일 수 있다. 끊긴 곳을 잇는 선을 그리지 않는다 — 끊긴 채로 자연스러운 표현 | `md/PLAN-route-data.md` "수신 공백이 났을 때" |
| `display_basis: timetable` | 예 — 전부 | "시간표 기준" 표시. 실시간 예측과 구분 | [02](02-stop-upcoming.md) "정보 근거에 따른 문구" |
| `schedule_status` unknown / no_service / out_of_period | 날짜에 따라 | 운행 없음·자료 미확인·기간 밖 각각의 빈 화면 | `md/05`, [03](03-figma-handoff.md) "상태별 도안" |
| 카드 `upcoming` 0·1·2개, `attention` 항목 | 예 | 빈 칸·확인 항목 배치 | [02](02-stop-upcoming.md), `md/11` 11장 |
| 실시간 끊김 (`information_status: stale`) | P4 서버 기능은 있음, 관측 없음 | 마지막 확인 시각 + 연결 끊김 표시. 추정 위치를 그리지 않는다 | `md/03`, `md/12` |

상태값 전체 목록은 [md/01 6장](../md/01-conventions.md)이다.

## 디자인이 정하지 않아도 되는 것

- 시각 계산·정렬·어떤 버스를 보일지 — 서버가 정해서 준다 ([03](03-figma-handoff.md) "프론트가 시간표에서 임의 ETA를 계산하지 않는다").
- 좌표·경로가 없을 때 채워 넣는 방법 — 채우지 않는다 (`CLAUDE.md` 5장).
