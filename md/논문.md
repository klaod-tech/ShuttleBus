# 논문 기록 — 셔틀 위치 품질과 도착 시간 예측

작성·확인: 2026-09-22. 문헌 검토 및 실험 후보를 기록한다. 구현 계약은 기존 `03`·`07`·`08`·`09`·`10`이 소유하며 이 문서는 새 계약을 만들지 않는다.

## 1. 연구 방향과 확인 수준

출발점이 된 조언(2026-09-22 전달): GPS가 대체로 잘 수신되며, 칼만필터·비선형 추정으로 수신 공백을 보완하고 신호 교차로를 주요 확인 지점으로 쓸 수 있다는 것이었다. **추가 질문은 할 수 없으므로 아래 판단은 우리가 자료와 문헌으로 정한다** (2026-09-22). 우리 노선에서 공백이 드물다는 실측 결과는 아직 없다.

연구 우선순위는 **정상 GPS 관측을 기본으로 하고 좌표 튐·신호 불량·수신 공백에 대비하는 보완 수단을 검토**하는 것이다. 정상 구간에서도 품질 검사는 필요하다. 관성 항법을 선택한다면 장애가 난 뒤에만 IMU를 켜는 방식이 아니라, 정상 수신 중에도 센서를 수집하고 시각·자세·편향을 맞춰야 공백을 보완할 수 있다(P2·P3를 참고한 적용 판단).

아래 P1~P5는 논문 식별자이며 프로젝트 단계 번호가 아니다. 출판사·저자 소속 기관의 공개 자료를 우선 확인했다. P3는 공개 본문 발췌(3·4.2·5절 포함), 나머지는 공개 초록·소개·서지 중심이다. 일부 본문 직접 열기는 403/429로 제한됐다. 본문 전체 독해·코드 재현·우리 장치 성능 검증은 수행하지 않았다. 다른 환경의 정확도 수치를 우리 셔틀 보장값으로 옮기지 않는다.

## 2. 관련 논문

### P1. 신호 교차로 지연을 도착 예측에 반영

**Bongsoo Son, Hyung Jin Kim, Chi-Hyun Shin, Sang-Keon Lee (2004). Bus Arrival Time Prediction Method for ITS Application. KES 2004, LNCS 3215, pp. 88–94.**

- DOI: `10.1007/978-3-540-30134-9_13` — [출판사](https://link.springer.com/chapter/10.1007/978-3-540-30134-9_13)
- 확인한 방법: 칼만필터로 버스 정거장에서 교차로 정지선까지 이동 시간을 예측하고 녹색 신호 정보와 비교해 정지 지연을 다음 구간에 반영한다.
- 활용: 현재 속도만으로 남은 시간을 계산하기보다 교차로 지연을 별도로 다루는 근거.
- 조건: 신호 정보가 필요하다. 실제 시스템의 신호 데이터 공급원·갱신 주기·우리 노선 접근 가능성은 초록으로 확인되지 않았다.
- 한계: 위치를 재확인하는 것과 신호 잔여시간을 아는 것은 다르다. 현재 좌표만으로 적색 신호가 언제 끝나는지 알 수 없다.

### P2. 여러 센서를 결합해 불량 GNSS 환경 보완

**Kai-Wei Chiang, Dinh-Thuan Le, Kuan-Ying Lin, Meng-Lun Tsai (2023). Multifusion schemes of INS/GNSS/GCPs/V-SLAM applied using data from smartphone sensors for land vehicular navigation applications. Information Fusion 89, pp. 305–319.**

- DOI: `10.1016/j.inffus.2022.08.012` — [저자 소속 대학의 초록·서지](https://researchoutput.ncku.edu.tw/en/publications/multifusion-schemes-of-insgnssgcpsv-slam-applied-using-data-from-/), [출판사](https://www.sciencedirect.com/science/article/pii/S1566253522001002)
- 확인한 방법: 스마트폰 IMU·GNSS·카메라·기준점(GCP) 정보를 EKF로 결합하며 영상 기반 위치 추정도 함께 사용한다.
- 활용: GNSS만으로 불안정한 구간을 다른 관측으로 보완하는 연구 근거.
- 조건: IMU는 가속도·회전을 측정하는 센서다. 이 논문의 전체 구성은 IMU만 추가한 GPS 장치와 같지 않으며 카메라·기준점 등의 조건을 함께 확인해야 한다.
- 한계: 좌표·속도·방향만 HTTP로 보내는 장치가 IMU 원시 자료까지 제공한다고 가정할 수 없다. 장치 사양과 실제 내보내기 자료 확인이 선행된다.

### P3. 튀는 관측을 필터에 그대로 넣지 않는 강건 추정

**Yi Dong, Dingjie Wang, Liang Zhang, Qingsong Li, Jie Wu (2020). Tightly Coupled GNSS/INS Integration with Robust Sequential Kalman Filter for Accurate Vehicular Navigation. Sensors 20(2), 561.**

- DOI: `10.3390/s20020561` — [출판사·본문](https://www.mdpi.com/1424-8220/20/2/561)
- 확인한 방법: GNSS 원시 관측과 관성 항법을 결합한다. 4.2절에서 예측과 관측의 차이(innovation) 및 그 분산에 기반한 검정으로 개별 GNSS 채널의 이상을 탐지·조정한다.
- 활용: 위치가 크게 튀는 경우 단순 평균으로 정상 좌표와 섞지 않고, 관측 품질과 모델 불확실성을 함께 평가하는 근거.
- 조건: 논문은 의사거리·도플러·반송파 등 원시 GNSS 관측을 사용한다. 최종 위도·경도만 받는 현재 전송 구상에 알고리즘을 그대로 붙일 수 없다.
- 적용 아이디어: 좌표 수준에서 시각·이동량·방향·정확도·예측 잔차를 함께 검사하는 별도 실험을 고려한다. 이는 논문 방법의 직접 구현이 아닌 프로젝트 적용 제안이다. 정당한 회전·우회까지 오탐하지 않는지 비교한다.

### P4. 비선형 모델로 ETA 갱신

**Avinash Achar, Akshaya Natarajan, Rohith Regikumar, B. Anil Kumar (2022). Predicting public transit arrival: A nonlinear approach. Transportation Research Part C 144, 103875.**

- DOI: `10.1016/j.trc.2022.103875` — [출판사](https://www.sciencedirect.com/science/article/pii/S0968090X22002881)
- 확인한 방법: 구간·운행 간 시공간 관계를 비선형으로 학습하고 숨은 상태 추정 문제로 구성하여 EKF와 입자필터를 비교한다.
- 활용: 구간별 이력과 새 관측을 이용해 남은 도착 시간을 조정하는 후보.
- 조건: 반복 운행 학습 자료가 필요하다. GPS 위치 복원 연구와 구분한다.
- 한계: 복잡한 필터가 단순 구간 통계보다 우리 소량 자료에서 우수하다는 근거는 아직 없다.

### P5. 실제 도착 관측으로 누적 예측 오차 보정

**Jinxing Shen, Qinxin Liu, Yining Zhang, Miao Yu (2025). A novel model incorporating deep learning and Kalman filter augmentation for route-level bus arrival time prediction with error accumulation mitigation. Expert Systems with Applications 281, 127622.**

- DOI: `10.1016/j.eswa.2025.127622` — [출판사](https://www.sciencedirect.com/science/article/abs/pii/S0957417425012448)
- 확인한 방법: 오프라인 LSTM·attention 예측을 온라인 칼만필터가 실시간 버스 도착 자료로 조정한다. 앞선 검색에서 제공된 출판사 초록을 확인했으며 이번 직접 본문 열기는 403으로 제한됐다.
- 활용: 관측이 새로 들어오면 누적 예측 오차를 보정한다는 근거.
- 한계: 정거장 도착 관측의 보정을 교차로 통과 관측으로 확장하는 것은 우리 실험 제안이다. 이 논문이 교차로 통과마다 보정한다고 확인한 것은 아니다.

## 3. 핵심 질문 3가지에 대한 답

조언에서 남은 세 가지 의문을 우리가 스스로 정해야 한다. 논문은 "그런 방법이 존재한다"는 근거일 뿐이며, 우리 장치·노선에서 되는지는 측정으로 답한다.

| 질문 | 논문에서 확인한 답 | 우리 프로젝트 판단 | 아직 확인할 것 |
|---|---|---|---|
| IMU를 함께 쓸 것인가? | **그런 방법이 있다.** P2·P3는 관성 센서와 GNSS를 결합한다 | 첫 구성에서는 쓰지 않는다. GPS만으로 공백 빈도를 먼저 재고, 공백이 문제로 확인되면 추가를 검토한다 | 우리 단말이 원시 센서를 내보내는지, 시각 동기화·고정 장착이 되는지 — 단말 사양 확인 |
| 신호 정보를 받을 것인가? | **그런 방법이 있다.** P1은 녹색 신호 정보를 사용한다 | 공급원을 우리가 확보하지 못하면 쓰지 않는다. 대안은 교차로 구간의 지연 분포를 실측으로 학습하는 것이다 | 공개 신호 정보(예: 지자체·국가 교통정보 개방 자료)에 이 노선 교차로가 있는지 우리가 조사 |
| 무엇을 기준으로 예측을 갱신할 것인가? | **새 관측으로 보정하는 근거는 있다(P5).** 교차로별 보정은 이번 자료에서 확인하지 못함 | 우선 **정거장 관측**을 갱신 기준으로 한다 — 이미 수집 중이고 판정이 검증돼 있다. 교차로 통과는 좌표가 모이면 추가 실험 | 교차로 통과를 좌표만으로 신뢰성 있게 판정할 수 있는지 (신호대기·정차 구분) |

더 앞선 질문 묶음도 미정으로 남긴다: 측정 주기와 전송 주기의 실제 값은 장치·목적에 따라 검증해야 하며 논문 하나로 1초를 확정하지 않는다. 통신 공백과 측정 실패는 단말 저장 여부·측정/수신 시각으로 구분한다. 신호대기와 승하차 정차는 좌표·속도만으로 항상 구분되지 않으므로 현장 기준 기록이 필요하다.

## 4. 상황별 적용 후보

아래 표는 연구·검증 계획이며 새 실행 규칙이 아니다. 임계값은 정하지 않았다.

| 상황 | 먼저 확보·확인할 정보 | 후보 처리 | 주의점 |
|---|---|---|---|
| 정상 GPS | 측정/수신 시각, 정확도, 차량·회차·방향 | 품질 검사 후 실제 관측 활용 | 필터 적용 여부와 무관하게 원본 보존 |
| 좌표 한두 점 튐 | 이동량·시간차·정확도·후속 좌표·예측 잔차 | P3를 참고한 이상치 거부·가중치 조절 실험 | 일반 칼만필터도 잘못된 관측에 끌려갈 수 있음 |
| 통신만 중단 | 단말은 측정 중인지, 오프라인 기록 여부 | 재연결 후 원래 측정 시각으로 재전송·검증 | 서버에 늦게 도착한 기록을 현재 위치로 표시하지 않음 |
| GNSS 측정 공백, IMU 있음 | 연속 IMU·동기화·장착 자세·편향 | P2·P3 기반 단기 내부 추정 비교 | 공백이 길수록 오차가 커질 수 있음. 표시·방문 확정에 자동 사용하지 않음 |
| GNSS 측정 공백, 추가 센서 없음 | 마지막 유효 위치와 시각 | 현행 마지막 확인 위치·확인 중 동작 유지 | 급정지·회전·우회를 알 수 없어 관측 위치를 만들어낼 수 없음 |
| GNSS 복귀 | 새 좌표의 정확도·연속성·방향 | 유효 관측으로 추정 재보정 후보 | 복귀 첫 점을 무조건 신뢰하지 않음 |
| 신호 교차로 접근·대기·통과 | 교차로 위치·방향·실제 통과시각, 가능하면 신호 정보 | P1 신호 지연 반영, P5 기반 이벤트 보정 비교 | 속도 0만으로 적색 신호·승하차를 구별하지 않음 |

**현행 계약과 경계:** [07](07-gps-detection.md) 9장은 공백 중 추정 좌표로 공개 위치를 채우지 않으며 [10](10-stop-discovery.md)은 관측하지 않은 가상 이동을 금지한다. 따라서 이 문서의 내부 필터 실험 후보를 학생 지도·방문 확정에 연결하려면 별도의 설계 변경 계획과 승인이 필요하다. 이번 요청은 문헌 기록으로 처리했고 해당 계약·API·스키마는 변경하지 않았다.

## 5. 확보 자료와 검증 계획

1. 먼저 실제 노선의 수신 공백 빈도·지속시간·좌표 튐 비율을 측정한다. '대체로 끊기지 않는다'는 전언을 우리 노선의 검증 결과로 기록하지 않는다.
2. 측정 시각과 서버 수신 시각을 모두 확보한다. IMU를 쓸 경우 샘플 시각·단위·센서 좌표축·장착 방향·결측을 확인한다. 위치 단말 이름과 출력 필드부터 확인한다.
3. 정거장 도착/출발과 주요 교차로 통과·대기 시각을 별도 현장 기준으로 남긴다. 같은 GPS를 정답과 시험 입력 양쪽에 쓰지 않는다.
4. 정상 기록 일부를 가린 공백 시험과 튐 주입 시험은 **합성 장애 시험**으로 표시하고 실제 불량 구간 시험과 구별한다. 정상 자료만 가린 결과로 터널·다중경로 성능을 보장하지 않는다.
5. 위치는 공백 길이별 오차·이상점 오탐/미탐·복귀 후 안정화를, ETA는 시간대·예측 거리·교차로 통과 전후 오차를 평가한다. 학습 운행과 평가 운행을 분리한다.
6. 단순 기준선(마지막 위치 유지, 구간 이력 ETA)과 필터 후보를 비교한다. IMU·신호 정보의 추가 효과도 각각 비교한다. 실측 표본·설치 허가 등 [ROADMAP](ROADMAP.md)의 선행 조건은 그대로다.

## 6. 검증 상태와 남은 질문

- 완료: 논문 5편의 공개 자료 확인, 질문 3개에 대한 근거·미확인 항목 분리, 현재 계약과 적용 후보의 경계 확인.
- 미실행: 논문 전체 본문 대조, 알고리즘 구현·실험 재현, 실제 단말·노선 측정, 코드 시험.
- **우리가 스스로 정해야 하는 것** (추가 질문 경로 없음, 2026-09-22):
  - 단말: 무엇으로 좌표를 받을지. 후보는 휴대폰 로거(Traccar Client 등)이며 IMU는 첫 구성에서 제외한다.
  - 측정·전송 주기: 1초 측정을 시작값으로 잡고, 실제 배터리·통신량·정확도를 재서 조정한다.
  - 갱신 기준: 정거장 관측을 기준으로 시작한다. 교차로는 좌표가 쌓인 뒤 판정 가능성부터 확인한다.
  - 신호 정보: 공개 자료에 이 노선 교차로가 있는지 조사한다. 없으면 지연 분포 학습으로 대체한다.
  - 평가 기준 자료: 탑승 중 수동 기록(정거장 도착·출발)을 정답으로 쓰고, 같은 GPS를 정답과 입력에 동시에 쓰지 않는다.
