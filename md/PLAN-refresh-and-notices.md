# 화면 갱신과 공지 — 주기 조회 없음·접속 시 공지 팝업

- 분야: 서버
- 작업: SB-0028

2026-10-06 사용자 결정. 이 문서는 **왜 이렇게 정했는지**를 남긴다. 규칙의 정본은 `12` 3장 '갱신 시점'·2장, `11` 5장, `13` 6장, `md_frontend/01` '공지 표시 범위'·`02` '갱신'이다.

## 1. 출발점 — SB-0028 '정보 유효 종료 시각'

화면에 떠 있는 정보(예: "천안아산역 도착 확인")는 일정 시간이 지나면 믿을 수 없다(도착 확인은 `arrived_freshness_seconds`). 판정은 서버가 하지만 응답에 "몇 시까지 유효"가 없어, 화면이 다시 묻지 않으면 낡은 정보가 남는다. 지금까지는 화면이 30초마다 다시 묻는 **예비 조회**(`refresh_after_seconds`)로 가렸다.

| 안 | 내용 | 결과 |
|---|---|---|
| A | 30초마다 예비 조회 (기존) | 학생 수에 비례한 서버 부하. 최대 30초 낡음 |
| B | 항목마다 `valid_until` | API 변경·화면 구현 증가 |
| C' | 연결 중엔 2분 예비 조회 | 부하 1/4, 최대 2분 안에 자동 회복 |
| **D (채택)** | **예비 조회 없음.** 서버 알림 + 앱 복귀·재연결·당겨서 새로고침. 우측 상단 갱신 시각 | 부하 거의 없음. 알림을 놓치면 학생이 갱신 시각을 보고 직접 새로고침 |

D를 고른 이유: 네이버 지도처럼 "확인하고, 필요하면 내가 다시 받는다"가 익숙하고(사용자 경험), 서버 부담이 학생 수와 무관하다. 대신 받아들인 것: 연결이 조용히 끊긴 것을 아직 모르는 동안(Socket.IO 기본 설정으로 최대 약 45초)의 알림은 놓친다 — 갱신 시각이 멈춘 것으로 학생이 알 수 있다.

## 2. D의 전제 — 시간이 지나서만 바뀌는 정보도 알림으로 나가야 한다

예비 조회가 가려 주던 빈틈 두 곳을 확인했다 (2026-10-06).

| 빈틈 | 원인 | 처리 |
|---|---|---|
| 도착 확인 3분 경과 | 30초 상태 확정 작업이 **회차 상태 내용**만 비교했다. 도착 신선도는 후보 분류에만 쓰여 내용이 같으니 확정·알림이 없었다. `12` 2장은 이미 '신선도 만료'를 `candidates:changed` 발행 조건으로 적어 두었다 — 구현이 빠졌던 것 | 상태 확정 비교에 **후보 분류 서명**도 넣는다 (`is_current`). 분류가 바뀌면 새 버전·`candidates:changed`. 정거장 카드도 이 알림으로 다시 조회한다 |
| 공지 자연 만료 | 공지는 생성·조기 만료 때만 알림 | 공지를 **접속 시 팝업**으로 바꿔 만료 알림 자체가 필요 없다 (3장). 응답의 `expires_at`으로 화면이 스스로 숨긴다 |

## 3. 공지 — 접속 시 팝업

| 항목 | 방식 |
|---|---|
| 표시 | 앱에 **들어올 때** 유효 공지를 팝업으로. 유효 기간 동안 접속할 때마다 |
| 버튼 | **오늘 하루 보지 않기 \| 닫기.** 오늘 하루 보지 않기는 그 공지를 오늘 다시 띄우지 않는다(내일 다시). 닫기는 지금만. 기억은 기기에만 — 학생 계정이 없다 |
| 새 공지 | 올리는 순간 `notice:changed` → 켜져 있는 화면은 공지를 다시 받아 **아직 본 적 없는 새 공지만** 팝업 |
| 날짜 변경 | 앱을 강제로 재시작하지 않는다. 날짜가 바뀐 것을 알면(0시에 켜져 있거나 다음 날 복귀) **새 접속처럼** 처리 — 공지 다시 받기, 오늘 하루 보지 않기 해제. 막차 22:30이라 사실상 다음 날 처음 열 때 |
| 버스 카드 | 공지를 붙이지 않는다 — 카드에 정보가 너무 많아진다 |
| 예약 공지 | 두지 않는다. **운영 규칙: 공지는 해당일 전날 또는 당일에 올린다.** 미리 올릴 일이 잦아지면 `notices`에 빈칸 허용 시작 시각 열을 더한다(마이그레이션·승인) — 기존 공지에 영향 없음 |

사용자 의견(2026-10-06): 9/10~9/15처럼 며칠 이어지는 사정이면 그 기간 동안 접속할 때마다 띄운다. 이런 '접속 시 팝업 + 오늘 하루 보지 않기'는 흔한 방식이라 학생에게 익숙하다.
